экран Редактирование задачи

1) данный экран открывается из нескольких мест
- создание новой проектной задачи (см. экран Редактирование проекта - список задач)
- редактирование проектной задачи (см. экран Редактирование проекта - список задач)
- создание новой отдельной задачи (см. экран Список задач п.3)
- редактирование задачи (см. экран Список задач п.2)
- редактирование задачи (см. экран Сегодня)
- редактирование задачи (см. экран Работа)

При создании новой задачи - отображаем кнопки "Отмена" и "Добавить"
При редактировании - отображаем кнопки "Отмена" и "Сохранить"
При нажатии на любую из этих кнопок - возвращаемся на тот экран, откуда пришли.

2) На форме отображаем поля:
- сфера - выпадающий список
- цель - выпадающий список (показываем цели, выбранной сферы), может быть NULL
- проект - отображаем название проекта (read only)
- статус - выпадающий список (справочная таблица), по умолчанию = активна
- название - строка
- описание - многострочный текст
- признак привязки ко времени (встречи, мероприятия и т.п.) - чек-бокс "Встреча", bool по умолчанию = false
- дата старта - календарь (по умолчанию = сегодня, время 00:00 в локальном времени клиента)
- дата финиша - календарь (по умолчанию = сегодня + 7 дней, время 00:00 в локальном времени клиента)
- длительность (затраты времени планируемые в минутах) - целое число > 0, по умолчанию = 30
- время встречи - HH:MM  (для встреч) - контрол выбора времени, NULL
- время на дорогу в минутах (для встреч), целое число, например 20, NULL
- приоритет «важность», целое число от 0 до 3, по умолчанию = 0
- приоритет «последствия», целое число от 0 до 3, по умолчанию = 0
- прогресс – целое число от 0 до 100 (по умолчанию = 0)
- delay-to отложить до - отображаем дату-время (если есть) до которого откладывается выполнение задачи - формат dd.MM.yyyy HH:mm (read only)
- количество откладываний (число лягушек) - просто отображаем, если > 0 (read only)
- затраты времени фактические (сохраняются в отдельную таблицу) - см. п.5

3) особенности отображения проектных и отдельных задач
задачи бывают проектные и отдельные
3.1) для отдельных задач мы позволяем выбрать сферу и цель, а поле "проект" скрываем вообще.
при редактировании сферу и цель также можно поменять
3.2) для проектных задач поля сфера и цель копируются из проекта и менять их тут нельзя.
мы отображаем их обычным текстом, как и название проекта.

4) особенности отображения встреч
чек-бокс "Встреча" позволяет выбрать тип задачи: обычная или встреча.
переключение данного чекбокса - меняет вид отображения временных параметров задачи.
менять тип можно только при создании новой задачи (при редактировании - нельзя)

4.1) для обычной задачи
выводим поля:
- дата старта - календарь (по умолчанию = сегодня, время 00:00 в локальном времени клиента)
- дата финиша - календарь (по умолчанию = сегодня + 7 дней, время 00:00 в локальном времени клиента)
- длительность (затраты времени планируемые в минутах) - целое число > 0, по умолчанию = 30

и не показываем поля:
- время встречи - HH:MM  (для встреч) - контрол выбора времени, NULL
- время на дорогу в минутах (для встреч), целое число, например 20, NULL

4.2) для встречи
выводим поля: 
- дата - календарь (по умолчанию = сегодня, время 00:00 в локальном времени клиента)
- время встречи - HH:MM  (для встреч) - контрол выбора времени, NULL
- длительность (затраты времени планируемые в минутах) - целое число > 0, по умолчанию = 30
- время на дорогу в минутах (для встреч), целое число, например 20, NULL

при выборе даты встречи, мы заносим выбранное значение в оба поля "дата старта" и "дата финиша", то есть для встреч интервал всегда = 1 дню

5) ввод трудозатрат
- отображаем список фактических трудозатрат в виде таблицы с 2 колонками: дата и количество минут, например:
| 01.06.2026 | 30 |
| 04.06.2026 | 15 |
и т.п

кнопка с символом "+" для добавления новой записи о трудозатратах - открывает мини-диалог, в котором отображаем календарь для выбора даты (по умолчанию = сегодня), и поле для ввода трудозатрат в минутах (по умолчанию = 30). 

дата отображается в виде ссылки, при клике на которую - также отображаем мини-диалог, в котором можем изменить дату и трудозатраты в минутах.
для всех дат в трудозатратах - время 00:00 в локальном времени клиента
