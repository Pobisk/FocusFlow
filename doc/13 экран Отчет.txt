экран Отчет

Отображает время, которое мы потратили на работу над своими задачами, в том числе время затраченное на целевые проекты/задачи. 

В различных временных интервалах и разрезах:
- за неделю по дням;
- за месяц по неделям;
- за квартал по неделям;
- за год по месяцам.

для выбора интервала, см. Типовые элементы управления п.2, по умолчанию текущая неделя.

1) формирование отчета на бэке

на вход мы получаем выбранный интервал времени:
- тип интервала
- дата первого дня в интервале

формируем элементы отчета
это структура report_item, с полями:
- order - порядковый номер, для сортировки на фронте
- caption - заголовок элемента
- plan_minutes - плановое время в минутах
- fact_minutes - фактическое время в минутах
- fact_percent - фактическое время в %
- goal_minutes - целевое время в минутах
- goal_percent - целевое время в %

на выходе возвращаем:
- массив структур report_item
- суммарный элемент report_item

Плановое время в день - 8ч (константа)

1.1) если тип интервала - неделя
мы строим массив из 7 элементов для каждого дня этой недели, для каждого элемента заполняем:
- order - 1, 2, 3, 4, 5, 6, 7
- caption - ПН, ВТ, СР, ЧТ, ПТ, СБ, ВС
- plan_minutes - 8ч * 60 = 480
- fact_minutes - суммируем значения из таблицы с фактическими трудозатратами для всех задач за этот день
- fact_percent = fact_minutes / plan_minutes * 100
- goal_minutes - суммируем значения из таблицы с фактическими трудозатратами для целевых задач за этот день
- goal_percent = goal_minutes / plan_minutes * 100

в конце вычисляем суммарный элемент 
- caption - Всего
- plan_minutes - сумма plan_minutes всех элементов
- fact_minutes - сумма fact_minutes всех элементов
- fact_percent = fact_minutes / plan_minutes * 100
- goal_minutes - сумма goal_minutes всех элементов
- goal_percent = goal_minutes / plan_minutes * 100

1.2) если тип интервала - месяц
сначала мы должны определить сколько недель входит в данный месяц, при этом мы руководствуемся правилом:  
неделя считается входящей в месяц (и соответственно в квартал) если не менее 4-х дней недели входит в месяц.

таким образом, например для апреля 2026 у нас получается 5 недель:
- с 30 марта по 5 апреля
- с 6 апреля по 12 апреля
- с 13 апреля по 19 апреля
- с 20 апреля по 26 апреля
- с 27 апреля по 3 мая

далее мы строим массив из N элементов для каждой полученной недели, для каждого элемента заполняем:
- order - 1, 2, 3, 4, и т.д.
- caption - выводим календарное число для понедельника этой недели и сокращенное название месяца из 3-х символов, например: 30 мар, 6 апр, 13 апр, 22 июн, и т.п.
- plan_minutes - 8ч * 60 * 7 = 3360
- fact_minutes - суммируем значения из таблицы с фактическими трудозатратами для всех задач за эту неделю
- fact_percent = fact_minutes / plan_minutes * 100
- goal_minutes - суммируем значения из таблицы с фактическими трудозатратами для целевых задач за эту неделю
- goal_percent = goal_minutes / plan_minutes * 100

суммарный элемент вычисляем аналогично

1.3) если тип интервала - квартал
так же как и для месяца, сначала определяем количество недель. руководствуемся тем же правилом.

например для 2 квартала 2026 у нас получится 13 недель:
- с 30 марта по 5 апреля
- с 6 апреля по 12 апреля
- с 13 апреля по 19 апреля
...
- с 15 июня по 21 июня
- с 22 июня по 28 июня

хвостик из 2-х дней: 29 и 30 июня - попадает в отчет за июль или 3-й квартал.

далее строим все элементы, так же как и для месяца.

1.3) если тип интервала - год
мы строим массив из 12 элементов для каждого месяца этого года, для каждого элемента заполняем:
- order - 1, 2, 3, и т.д.
- caption - выводим сокращенное название месяца из 3-х символов, например: янв, фев, мар, апр, июн, и т.п.
- plan_minutes - 8ч * 60 * (количество дней в этом месяце) = ????
- fact_minutes - суммируем значения из таблицы с фактическими трудозатратами для всех задач за этот месяц
- fact_percent = fact_minutes / plan_minutes * 100
- goal_minutes - суммируем значения из таблицы с фактическими трудозатратами для целевых задач за этот месяц
- goal_percent = goal_minutes / plan_minutes * 100

суммарный элемент вычисляем аналогично

2) отображение отчета на фронте
Отображение отчета в виде вертикальной гистограммы, где столбики идут горизонтально сверху вниз.
общая ширина гистограммы - 100%,
общая ширина столбика - фактическое время в %
ширина закрашенной части - целевое время в %

пример отображения (макет):
| ПН | ▓▓▓▓▓▓▓▓░░░░░░░░░░░            |
| ВТ | ░░░░░░░░░░░░░░░░                |
| СР | ▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░     |
| ЧТ | ▓▓▓▓▓▓▓▓░░░░░░░░░░░            |
| ПТ | ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                |

Внизу выводим суммарную сводку за весь интервал в %
Факт 60% / Цель 9%

Примечание: фактическое или целевое время, может иногда превышать плановое, это если мы отработали в день более плана - 8 ч. В этом случае ограничиваем ширину столбика шириной гистограммы, то есть если факт или цель > 100%, то принять их равными 100%.
Но в суммарной сводке выводим как есть.

Назначение данного экрана - видеть сколько времени идет на работу вообще, и сколько на целевые действия. 
В идеале, например, должно быть не менее 60% работы, и не менее 20% целевых действий.
