Концепция алгоритма выбора действия (черновик)

Нам нужно рассчитать какую задачу следует взять в работу сейчас.
Мы вычисляем некую количественную оценку Score, затем сортируем по убыванию и берем TOP 1

На оценку влияют: 
1) параметры действия 
- "Важность" 
- "Последствия" 
- "Дней до дедлайна" здесь например так: берем период задачи, разделяем его на 3 части, находим текущий момент времени на этом периоде. далее для 1-й части функция y=x, для 2-й части функция y=0.3*x, для 3-й части функция y=2*x
- количество отказов выполнять действие

2) параметры проекта
- проактивный (целевой) проект
- проект застопорился (давно не было движения)

3) параметры сферы
- низкая оценка удовлетворенности в данной сфере
- давно не было движения в данной сфере

Все параметры влияет со своими коэффициентами, которые пользователь может менять в настройках

Фильтрация:
  ✓ Статус ≠ «Ожидание» / «Завершено»
  ✓ Входит в диапазон дат
  ✓ Не пересекается с жёсткими встречами
  ✓ Учитывает дневной лимит нагрузки

Результат: ТОП-1 действие для фокуса.
После 3 отказов подряд — предложить пользователю скорректировать приоритеты.
