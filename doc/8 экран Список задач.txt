экран Список задач

1) Загрузка списка 

на этом экране отображается список задач за какой-то период (см. Типовые элементы управления п.2). По умолчанию, тип интервала = день, текущий интервал = сегодня.

задачи на бэке фильтруются по интервалу так: 
"дата конца интервала" >= "дата старта задачи" и "дата начала интервала" <= "дата финиша задачи"

также возможна фильтрация по сферам (см. Типовые элементы управления п.1)

также есть 3 чек-бокса для дополнительных фильтров:

"Все"
задача может быть в одном из 3 статусов: активна, завершена, отменена.
по умолчанию загружаются только активные задачи.
при активации данного чек-бокса - загружаем все (без фильтрации по статусам).
назначение: посмотреть завершенные и отмененные задачи.

"Отдельные"
задачи бывают проектные (есть связь с проектом) или отдельные.
по умолчанию загружаем все задачи.
при активации данного чек-бокса - загружаем только отдельные задачи.
назначение: посмотреть только отдельные задачи.

"Встречи"
задачи бывают с привязкой ко времени - "встречи", и обычные.
по умолчанию загружаем все задачи.
при активации данного чек-бокса - загружаем только задачи типа "встреча".
назначение: посмотреть только встречи

Для запроса списка мы передаем на бэк:
- выбранный интервал времени
- значения чек-боксов (если отмечены). различные комбинации чек-боксов могут давать разные выборки данных.

фильтрация по сферам выполняется на фронте

2) отображение задачи

Для каждой задачи мы отображаем:
- Иконка ракета (отображаем только для активных задач, которые не являются встречами)
- Иконка цели (если задача привязана к цели)
- название (см. Типовые элементы управления п.3), примеры:
	Р Проект 1 / Задача 1 
	Б Запустить сайт Ян-Шэн / Выбрать стек разработки
	С Купить билеты в цирк
	З Пройти обследование у офтальмолога / 🕑Прием 12.06.2026 10-30 (дорога 20)
примечание, для табличного представления делим на 3 колонки:
| Код сферы | Название проекта | Название задачи |

- статус задачи
- прогресс, например: 33%
- количество откладываний (лягушка)

Названия проектов и задач отображаются в виде ссылок.
Клиент может нажать на ссылки названия проекта или задачи, и что-то поменять в их свойствах.
Если нажать на иконку-ракету у задачи, то мы переходим на экран "Работа" с уже выбранной задачей.

3) добавление новой задачи
Выводим кнопку "Добавить" - при нажатии открываем экран добавления новой задачи. Задача будет отдельная, то есть не привязанная к проекту. Проектные задачи создаются на экране редактирования проекта.

4) отображение списка
для десктопа выводим список в виде таблицы с колонками, иначе - список элементов (по одному в строке).

5) Что дает клиенту данный экран:
- просмотр списка активных задач на сегодня, или любой другой период времени.
- создание новой задачи (отдельной)
- посмотреть завершенные и отмененные задачи за прошлые периоды времени
- посмотреть задачи на будущие периоды времени
- посмотреть список встреч на определенный день, или любой другой период времени.
- Клиент может перейти на экран редактирования проекта или задачи, чтобы поменять какие-то параметры.
- Клиент может сделать выбор задачи сам, кликнуть на ракету, и перейти на экран "Работа".
