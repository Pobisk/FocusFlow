экран Список проектов

1) Загрузка списка 

на этом экране отображается список проектов за какой-то период (см. Типовые элементы управления п.2). По умолчанию, тип интервала = неделя, текущий интервал = текущая неделя.

проекты на бэке фильтруются по интервалу так: 
"дата конца интервала" >= "дата старта проекта" и "дата начала интервала" <= "дата финиша проекта"


также возможна фильтрация по сферам (см. Типовые элементы управления п.1)

также есть 1 чек-бокс "Все"
проект может быть в одном из 3 статусов: активен, завершен, отменен.
по умолчанию загружаются только активные проекты.
при активации данного чек-бокса - загружаем все (без фильтрации по статусам).
назначение: посмотреть завершенные и отмененные проекты.

Для запроса списка мы передаем на бэк:
- выбранный интервал времени
- значение чек-бокса (если отмечен)

фильтрация по сферам выполняется на фронте

2) отображение проекта

Для каждого проекта мы отображаем:
- Иконка цели (если проект привязан к цели)
- название (см. Типовые элементы управления п.3), примеры:
	Р Проект 1
	Б Запустить сайт Ян-Шэн
	З Пройти обследование у офтальмолога
примечание, для табличного представления делим на 2 колонки:
| Код сферы | Название проекта |

- статус проекта
- признак наличия активной задачи (вычисляемое поле), bool, если true - зеленый чек-бокс, иначе - красный.
- прогресс, например: 33%
- скорость (вычисляемое поле), число с одним знаком после запятой, если >= 0.8 выводим зеленым цветом, иначе - красным. примеры: 0.0 0.5 0.9 1.0 1.5 2.0 3.7 и т.п. 

Названия проектов отображаются в виде ссылок.
Клиент может нажать на ссылку названия проекта, и что-то поменять в его свойствах.

примечание для вычисляемых полей:
они вычисляются на бэке при загрузке списка.
- признак наличия активной задачи - в списке задач данного проекта ищем хотя бы одну активную задачу;
- скорость (см. ниже)

3) алгоритм вычисления скорости проекта
ВАЖНО: вычисляется на бэке только для активных проектов, для  остальных вернуть NULL. нужна отдельная функция, так как параметр скорость проекта используется в алгоритме выбора задачи.

берем интервал проекта.
Дату старта принимаем за 0%
Дату финиша + 1 день - принимаем за 100%
Если текущий момент времени выходит за границы интервала, то берем граничные значения.

Далее берем текущий момент времени - и находим сколько % времени проекта прошло.
Если прошло 0% времени - вернуть NULL

Например: проект стартовал 01.06.2026, дата финиша - 10.06.2026. Сейчас - 04.06.2026 15:37:48.
переводим все 3 момента времени в числовое представление, например количество секунд.
для даты финиша берем + 1 день, то есть в нашем примере момент финиша = 11.06.2026, так как это "дата ПО".
нормируем в % выражении, и получаем, что сейчас прошло примерно 37,548 % времени.
если прошло менее 1 % времени, то принимаем его равным 1%.

Затем берем параметр "прогресс" проекта, и делим его на найденную величину "сколько % времени проекта прошло".
Результат округляем до 1 знака после запятой.

примеры:
прогресс 0%
прошло времени 37,548%
результат - 0.0

прогресс 25%
прошло времени 37,548%
результат - 0.7

прогресс 33%
прошло времени 90%
результат - 0.4

прогресс 50%
прошло времени 37,548%
результат - 1.3

Данная характеристика позволяет приближенно оценить прогресс выполнения проекта на сегодня, относительно срока проекта. 
В свойствах проекта клиент может менять прогресс и дату завершения, при этим скорость будет меняться.

4) добавление нового проекта
Выводим кнопку "Добавить" - при нажатии открываем экран добавления нового проекта.

5) отображение списка
для десктопа выводим список в виде таблицы с колонками, иначе - список элементов (по одному в строке).

6) Что дает клиенту данный экран:
- просмотр списка активных проектов на текущую неделю, или любой другой период времени.
- создание нового проекта
- посмотреть завершенные и отмененные проекты за прошлые периоды времени
- посмотреть запланированные проекты на будущие периоды времени
- перейти на экран редактирования проекта и поменять какие-то свойства
- отследить, что по всем активным проектам назначена активная задача
- добавить новую задачу в проект
- оценить прогресс и скорость выполнения проекта, если низкие, то предпринять какие-то действия, например повысить приоритет для задач этого проекта, пересмотреть сроки, и т.п.

В идеале - для каждого активного проекта должна быть определена следующая активная задача, и скорость проекта должна быть зеленой.
