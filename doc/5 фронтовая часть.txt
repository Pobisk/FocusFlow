на первом этапе фронтовая часть будет реализована в виде сайта SPA с адаптивной версткой.
нужна верстка под:
- десктоп
- планшет
- смартфон

SEO-оптимизация для сайта не нужна, главное быстрота и отзывчивость интерфейса.

в будущем обязательно сделаем мобильное Android-приложение для планшета или смартфона.
мобильное приложение будет иметь возможность работы в оффлайн-режиме, с синхронизацией.
Это важная особенность - для реализации оффлайн режима нужно предусмотреть примерно следующее: 
- все сущности наследуются от BaseModel
- имеют первичный ключ UUID v7
- имеют внешний ключ user_id типа UUID v7
- имеют специальные служебные поля для синхронизации, например временные метки создания и изменения записи и т.п.
- возможно имеют служебное поле для признака удаленной записи

- спокойные рабочие тона, без петушиных цветов. 
- шрифты большие, удобно читаемые
