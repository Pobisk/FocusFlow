экран Редактирование проекта

данный экран открывается из нескольких мест
- создание нового проекта (см. экран Список проектов п.4)
- редактирование проекта (см. экран Список проектов п.2)
- редактирование проекта (см. экран Список задач п.2)
- редактирование проекта (см. экран Сегодня)
- редактирование проекта (см. экран Работа)

При создании нового проекта - отображаем кнопки "Отмена" и "Добавить"
При редактировании - отображаем кнопки "Отмена" и "Сохранить"
При нажатии на любую из этих кнопок - возвращаемся на тот экран, откуда пришли.

На форме отображаем поля:
- сфера - выпадающий список
- цель - выпадающий список (показываем цели, выбранной сферы), может быть NULL
- статус - выпадающий список (справочная таблица), по умолчанию = активен
- название - строка
- описание - многострочный текст
- дата старта - календарь (по умолчанию = сегодня, время 00:00 в локальном времени клиента)
- дата финиша - календарь (по умолчанию = сегодня + 7 дней, время 00:00 в локальном времени клиента)
- прогресс – целое число от 0 до 100 (по умолчанию = 0)
- список задач - отображаем список задач данного проекта. 
По каждой задаче отображаем название, статус и прогресс в %.
Название задачи отображаем в виде ссылки, при клике на которую уходим на экран редактирования задачи.
Также здесь отображаем кнопку для добавления новой задачи в проект. При нажатии уходим на экран добавления новой задачи (передаем туда сферу, цель и проект для авто-выбора).

где-то на форме разместить еще 2 кнопки (не отображаются при создании нового проекта) :
кнопка "Завершить" 
- в проекте меняем статус = завершен
- "дата финиша" = сегодня, время 00:00 в локальном времени клиента
- прогресс = 100
- сохраняем в БД
- возвращаем на тот экран, откуда пришли

кнопка "Отменить" 
- в проекте меняем статус = отменен
- "дата финиша" = сегодня, время 00:00 в локальном времени клиента
- сохраняем в БД
- возвращаем на тот экран, откуда пришли
