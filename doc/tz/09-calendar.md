# ТЗ-09: Календарь

## 1. Цель модуля

Отображать действия с точным указанием времени (встречи, мероприятия) на ближайшие N дней. Помогает пользователю не забыть о встречах и убедиться, что все временные события занесены в систему.

## 2. Зависимости

- Модуль **01 — Авторизация** (защита эндпоинтов).
- Модуль **05 — Действия** (действия с `is_time_bound = True`).

## 3. Концепция

Календарь показывает только действия, у которых `is_time_bound = True`. Это встречи, созвоны, приёмы — всё, что имеет точное время. Действия без точного времени (с периодом) в календаре не отображаются.

## 4. Backend

### 4.1. Эндпоинт

Файл: `backend/src/api/endpoints/calendar.py`

Защищён `Depends(get_current_user)`.

#### GET /api/calendar

Параметры запроса:
- `date_from: str` — начало периода (ISO, UTC)
- `date_to: str` — конец периода (ISO, UTC)

Выход: список `ActionRead` (только с `is_time_bound = True`)

Логика:
1. Выбрать все действия пользователя с `is_time_bound = True` и `status = "active"`.
2. Отфильтровать по диапазону: `exact_time BETWEEN date_from AND date_to`.
3. Отсортировать по `exact_time ASC`.
4. Вернуть список.

#### GET /api/calendar/today

Выход: список `ActionRead` (встречи на сегодня)

Логика:
- Выбрать действия с `is_time_bound = True` и `exact_time` в пределах сегодняшнего дня (UTC).
- Отсортировать по времени.

## 5. Frontend

### 5.1. Страница календаря

Путь: `/calendar` (доступна только авторизованным)

**Отображение:**
- Заголовок с текущей датой и кнопками "Назад" / "Вперед" (переключение по дням).
- Список встреч на выбранный день, отсортированный по времени:
  - Время (ЧЧ:ММ)
  - Код сферы
  - Название действия
  - Название проекта
  - Длительность (если указана)
  - Время на дорогу (если указано)
  - Статус

**Альтернативное отображение (если встреч на день мало):**
- Можно показывать на неделю вперёд списком, сгруппированным по дням.

**Действия:**
- При клике на встречу — открыть карточку действия для редактирования.
- Кнопка "Добавить встречу" — модальное окно создания действия с `is_time_bound = True`:
  - Название
  - Проект (выпадающий список)
  - Дата и время
  - Длительность (минуты)
  - Время на дорогу (минуты)
  - Описание

### 5.2. Интеграция с главным экраном

На главном экране, если на сегодня есть встречи, показывать уведомление:
"Сегодня встречи: [количество]. Проверить в календаре."

## 6. Критерии готовности

- [ ] Эндпоинт `/api/calendar` возвращает встречи за период.
- [ ] Эндпоинт `/api/calendar/today` возвращает встречи на сегодня.
- [ ] Страница календаря отображает встречи по дням.
- [ ] Можно переключать дни (назад/вперед).
- [ ] Можно добавлять встречи через модальное окно.
- [ ] На главном экране отображается напоминание о встречах.
