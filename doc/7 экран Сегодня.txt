экран Сегодня

Система загружает все задачи на сегодня.
То есть: "сегодня" >= "дата старта" и "сегодня" <= "дата финиша"
По задачам также загружается фактическое время на сегодня.

ВАЖНО: чтобы корректно определить на бэке дату сегодня, мы с фронта передаем дату сегодня, время = 00:00 в локальном времени клиента

Сначала выводим строку со сводной информацией по дню.
плановое время - 8ч (константа)
факт - сумма фактического времени для всех задач
целевое - сумма фактического времени для целевых задач
например: 
Время: план 8ч / факт 1ч 50м / целевое 45 м

Затем выводим задачи списком.
Примечание: для десктопа выводим список в виде таблицы с колонками, иначе - список элементов (по одному в строке).

Первыми в списке идут завершенные задачи, у них зеленый кирпичик.
Затем идут активные задачи, у которых дата финиша <= сегодня, у них красный кирпичик.
Затем идут активные задачи, у которых дата финиша > сегодня, но <= (сегодня + deadline_near дней, см. сущности п.7 "настройки"), у них желтый кирпичик.
Затем идут все прочие активные задачи, без кирпичика.
Последними отображаются отмененные задачи, у них синий кирпичик.

Для каждой задачи мы отображаем:
- Иконка ракета (отображаем только для активных задач, которые не являются встречами)
- Иконка цели (если задача привязана к цели)
- название (см. Типовые элементы управления - п.3), примеры для строчного представления :
	Р Проект 1 / Задача 1 
	Б Запустить сайт Ян-Шэн / Выбрать стек разработки
	С Купить билеты в цирк
	З Пройти обследование у офтальмолога / 🕑Прием 10-30 (дорога 20)
примечание, для табличного представления делим на 3 колонки:
| Код сферы | Название проекта | Название задачи |

- плановое время в минутах, например: 30
- фактическое время на сегодня в минутах, например 17 (там где нет - не отображаем)
- количество откладываний (лягушка)
- кирпичик (см. выше)

Если нажать на иконку-ракету у задачи, то мы переходим на экран "Работа" с уже выбранной задачей.

Что дает клиенту данный экран:
- фактическое время показывает, достаточно ли мы поработали сегодня, чтобы в конце дня получить чувство удовлетворенности и право на отдых и очистку головы от проблем.
- целевое время показывает, двигались ли мы сегодня к целям
- зеленые кирпичики, дают чувство удовлетворенности.
- красный кирпичик показывает, что эти задачи нужно выполнить обязательно сегодня!
- желтый кирпичик показывает, что лучше сделать эти задачи пораньше, чтобы не допускать просрочки.

Клиент может нажать на ссылки названия проекта или задачи, чтобы поправить параметры, поменять статус или внести фактические трудозатраты.
Клиент может сделать выбор задачи сам, кликнуть на ракету, и перейти на экран "Работа".
