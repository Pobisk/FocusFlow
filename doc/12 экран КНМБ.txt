экран КНМБ
КНБМ – это список «когда-нибудь, может быть»

Список задач, целей, желаний, которые не находятся в активной фазе работы. Прямо сейчас нет нужды их выполнять, но возможно в будущем мы захотим их сделать, или появится возможность для этого.

1) Загрузка списка 
на экране отображается список всех КНМБ
с возможностью фильтрации по сферам (см. Типовые элементы управления п.1)

также есть 1 чек-бокс "Все"
у КНМБ есть признак активности
по умолчанию загружаются только активные записи.
при активации данного чек-бокса - загружаем все (без фильтрации по статусам).
назначение: посмотреть не активные КНМБ.

Для запроса списка мы передаем на бэк:
- значение чек-бокса (если отмечен)

фильтрация по сферам выполняется на фронте

2) отображение КНМБ

Для каждой записи КНМБ мы отображаем:

- название (отображаем так же, как для проекта - см. Типовые элементы управления п.3), примеры:
	Р Провести встречи "1 на 1"
	Б Подготовить список клиентов
	З Пройти обследование уролога
примечание, для табличного представления название делим на 2 колонки:
| Код сферы | Название записи |

- признак активности (отображается только если выбран чек-бокс "Все")
- срок в днях (вычисляемое поле) – сколько оно здесь лежит (количество дней с момента создания записи - вычисляется на бэке в момент чтения списка, на основе поля created_at. ТОЛЬКО для активных записей, для неактивных вернуть NULL )

Название отображаем в виде ссылки - см п.4

3) добавление новой записи
Выводим кнопку "Добавить" - при нажатии открываем мини-диалог добавления новой записи КНМБ.
на диалоге 3 поля:
- сфера - выпадающий список
- название - текст
- активность - чек-бокс (по умолчанию включен)

4) редактирование записи КНМБ
название КНМБ отображается в виде ссылки, при клике на которую - также отображаем мини-диалог, в котором можем изменить свойства записи КНМБ

5) отображение списка
для десктопа выводим список в виде таблицы с колонками, иначе - список элементов (по одному в строке).

примеры табличного представления:
| Сфера | Название | Активна | Дней |

| Р | Провести встречи "1 на 1"   |  | 63 |
| Б | Подготовить список клиентов |  | 20 |
| З | Пройти обследование уролога |  |    |

примечание: в столбце "Активна" отображаем иконку-чекбокс

6) Что дает клиенту данный экран:
Назначение – записать сюда наши хотелки, или действия, которые мы в данный момент выполнить не в состоянии. Примерно раз в квартал заходим в этот список и анализируем – возможно что-то можно взять в работу, а что-то потеряло актуальность и можно удалить совсем. Все эти хотелки не должны загружать нашу голову сейчас. Голову нужно освободить.

Когда мы решаем взять что-то отсюда в работу, мы создаем проект или задачу с таким же именем, а запись КНМБ деактивируем.
