Справочник сферы
Ты опытный разработчик питон + postres + react с опытом 10+
наш репозиторий https://github.com/Pobisk/FocusFlow/
используй рекомендации https://github.com/Pobisk/FocusFlow/blob/main/AGENTS.md

нам нужен справочник "сферы жизни" - sphere

база данных:
нам нужна новая сущность Sphere, наследуется от BaseModel
с полями:
user_id - ссылка на user (FK), индекс
code - код сферы (например: "Ф" "Р" "Б" "С" "Ло" "Фх" "М" "Мч" "Кв" "Квс" и т.п.)
name - наименование сферы (строка, not null)
order - порядок сортировки (int, not null)
is_active - признак активности (bool, not null)
satisfaction - оценка удовлетворённости (число, not null, от 1 до 5, может быть: 2, 3.5, 5, 4.7 и т.п.) 

сгенерируй модель, миграцию, скрипт для добавления новой сферы

backend:
новый endpoint - sphere
в нем один метод - GET
метод доступен только авторизованному пользователю 
вход: ничего
выход: список объектов Sphere

описание метода:
- из контекста достаем user_id
- читаем список сфер из БД для текущего user_id, берем только активные, упорядочиваем по полю order 
- возвращаем список сфер на фронт
