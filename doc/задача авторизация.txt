Авторизация
Ты опытный разработчик питон + react с опытом 10+
наш репозиторий https://github.com/Pobisk/FocusFlow/
используй рекомендации https://github.com/Pobisk/FocusFlow/blob/main/AGENTS.md

разработай подсистему авторизации
сейчас нам достаточно простой авторизации по логину/паролю

база данных:
нам нужна новая сущность User с полями:
name - имя пользователя (строка, not null)
login - логин пользователя (строка, not null)
hash - хэш от пароля (строка, not null)
active - признак активности (bool, not null)

индекс по полю login

backend:
новый endpoint - auth
в нем один метод - POST 
вход: 
login - логин пользователя (строка, not null)
hash - хэш от пароля (строка, not null)

выход:
name - имя пользователя
access_token - JWT-токен для доступа к авторизованной части сайта (срок действия - 6 часов, добавь claim-ы какие нужны)

описание метода:
- читаем сущность User из БД по полю логин, 
если не нашли - вернуть ошибку авторизации "Не верные логин или пароль".
- сравниваем поле hash с тем, что пришло на входе,
если не совпадает - вернуть такую же ошибку авторизации "Не верные логин или пароль".
- проверяем флаг active,
если = false - вернуть ошибку авторизации "Пользователь заблокирован".

если все хорошо - генерируем JWT-токен для доступа и возвращаем (name + access_token).


frontend:
при входе на сайт, на главной странице отображается статичный текст (который там сейчас) и блок ввода логина/пароля с кнопкой "Войти".

при нажатии на кнопку "Войти"
- валидация полей (стандартные правила для логина и пароля)
- вычисляем хэш от пароля, преобразуем в строку в нижнем регистре
- вызываем метод api/auth
- если ошибка - отображаем текст ошибки
- если успешно - переходим на главный рабочий экран

на главном рабочем экране - пока только приветствие "Здравствуйте {name}"
все последующие экраны отображаются только авторизованному пользователю,
все последующие запросы к api только с токеном авторизации.
